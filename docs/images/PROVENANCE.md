# 界面截图来源

本目录的 PNG 是 MyAITools Streamlit 界面的真实截图，由项目维护者在本机用 Playwright（Microsoft Edge）拍摄，用于 README 展示，没有使用 AI 生成图像。

| 文件 | 尺寸 | 内容 | 说明 |
| --- | --- | --- | --- |
| `light-mode.png` | 1440 × 1100 | 系统雷达读数，浅色外观 | 数据来自本机 psutil 实时采集 |
| `dark-mode.png` | 1440 × 1100 | 系统雷达读数，深色外观 | 与浅色为同一次采集 |
| `jd-verdict.png` | 1440 × 1180 | JD 水分判定结果，浅色外观 | 使用测试用假数据渲染，用于展示判定卡；不是真实 API 返回 |
| `batch-analysis.png` | 1440 × 1180 | GUI 批量分析页（预览 + 进度 + 结果表） | 使用测试用假数据与 mock 分类结果，不是真实 API 返回 |

截图拍摄于 2026-10-28，对应仓库 `main` 分支上的界面实现。
